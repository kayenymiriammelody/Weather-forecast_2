# Weather-forecast_2
The Weather Forecast Application is a Python program that retrieves weather information for a location specified by the user. It uses the Open-Meteo Geocoding API to convert a place name into geographical coordinates, the Open-Meteo Forecast API to obtain weather predictions, and the MET Norway Locationforecast API as a secondary source.
